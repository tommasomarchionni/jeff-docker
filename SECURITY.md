# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| Latest minor release (e.g. `0.2.x`) | Yes |
| Older releases | No — upgrade first |

## Reporting a vulnerability

Please **do not** open a public issue. Use
[GitHub private vulnerability reporting](https://github.com/tommasomarchionni/jeff-docker/security/advisories/new).
You will get an acknowledgement within 7 days.

Vulnerabilities in Jeff itself should be reported to
[the upstream project](https://github.com/logan-markewich/jeff).

## Hardening guidance

See the [Security documentation](https://tommasomarchionni.github.io/jeff-docker/security/).
